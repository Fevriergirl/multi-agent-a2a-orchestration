# Contributing

This project values falsifiable experiments over theatrical claims about artificial consciousness.

Before opening a pull request:

1. explain which operational property the change tests;
2. identify the strongest alternative explanation;
3. add or update tests;
4. preserve the ledger and intention-locking order;
5. document any change to scoring, thresholds, or constitution rules;
6. run `npm test` and `npm run verify`.

A result that weakens the project hypothesis is useful. Do not hide negative findings.
