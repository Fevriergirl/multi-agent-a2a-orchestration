## 0.3.0 - 2026-06-19

First complete Haunted Studio source tree committed to this repository.

- Added six-condition ablation experiment runner.
- Added self-directed and assigned attention conditions.
- Added refusal, revision, audience, memory, and surprise-carryover feature flags.
- Added live-image generation adapter and post-generation visual audit.
- Added verified-artifact versus conceptual-canon status.
- Added human review capture and audience calibration evidence.
- Added trajectory reports with entropy, recurrence, acceptance, and review metrics.
- Added state forking for path-dependence experiments.
- Added state rebuilding from the authoritative append-only ledger.
- Added explicit memory corrections that append rather than rewrite history.
- Added Codespaces configuration and iPhone setup guidance.
- Added local-only A2A mailbox hardening and request-size limits.
- Expanded the test suite.
